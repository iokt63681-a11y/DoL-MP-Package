# JOB_REDESIGN_PLAN.md — 十二条零工线全面重做设计方案

> **设计原则**：严格对齐《`MOD_DESIGN_STANDARDS.md`》与《`VANILLA_DESIGN_NOTES.md`》。
> 1. **入口归位**：12 条零工全部挂载在原版对应的真实街区/店铺场景中，高街招工板（`MP Livelihood Hub` / `MP Extra Jobs Hub`）仅作为“打听各处营生去向的备忘木牌”，不再充当跨区瞬移菜单。
> 2. **把事件还给班次**：像原版 `Ocean Breeze Work` 与 `Spa Work` 一样，当班过程中直接触发**本店专属的顾客/工况小插曲（带互动抉择）**，并在打工结算时自然给予原版技能微幅成长（`<<tending>>`、`<<housekeeping>>`、`<<athletics>>` 等）。
> 3. **去数值化叙事晋升**：界面与拦截提示中**彻底清零 `Lv`、`等级 N`、`经验` 字样**，全部用“店东交代的权限、信物钥匙、熟客点名、工具换新”来呈现。
> 4. **首通与失败铁律**：所有里程碑首通奖励（`claimUniqueReward`）严格置入 `_ok` 成功分支内部；失败分支 `$mpJobResultPay = 0` 且绝不发放任何金钱、古董或线索。
> 5. **跨店供应链（Cross-Job Supply Chain）**：12 家店铺构成真实的城镇物产闭环（如农场红麦 → 面包房/咖啡馆；海礁鲜鱼/远洋渔船 → 鱼档/酒馆后厨/咖啡馆；孤儿院浆洗房 → 桑拿房/裁缝铺；跑腿行串联钟表铺与各店加急单）。

## 二、样板级零工深度重做细案（鱼档 `MP Job Fish` & 桑拿 `MP Job Spa`）

### 样板 A：海礁鱼档（`MP Job Fish` — 梅尔街码头栈桥）

#### 1. 场景定位、真实入口与时间/警觉门控
- **挂载位置**：原版 `:: Docks`（梅尔街码头，`$location = "docks"`，`$outside = 1`）。
- **日夜双态机制**：
  - **白昼与晨昏（`06:00–20:59`）**：早市鱼贩拖出碎冰筐开秤，栈桥人声鼎沸，可进行近岸撒网、攀外礁下竿、刮鳞分筐，无夜间警觉风险。
  - **夜间暗潮（`21:00–05:59`）**：开启码头夜间警觉条（`<<mpalertinit "docks">>`），灯塔光束扫过水面。只有已在鱼档站稳脚跟（拿到加固竿与夜钓灯）的熟手才能下海**夜钓外海**；撒网或攀礁会激起水花增加警觉度（`<<mpalert 6>>`），蹲在避风处刮鳞则会降低警觉度（`<<mpalert -5>>`）。

#### 2. 常驻人物与微故事递进（无数字等级）
- **老鱼贩（档主）**：沉默寡言、左手虎口有旧鱼钩疤。从最初“踢了踢饵桶让你先下近岸网”，到“赊给你好饵”、“换上缠新麻绳的加固竿”、“把顺风的头等鱼摊交给你看管”，最后“把轻便舢板与小艇铜钥匙抛进你怀里”。
- **梅尔街酒馆采买厨师（熟客）**：清早赶来栈桥挑银鳕鱼柳，只认你剔过刺、铺过湿海带的冷鲜竹篓（触发 `MP Job Followup Fish` 与后厨供货联动）。
- **老码头工（工友）**：蹲在石阶上教你用牙咬线打水手结，风浪大时与你搭手拖回撞歪的活水网箱（`MP Job Partner Fish 2`）。

#### 3. 班次动作设计（4 个差异化岗位）
| 选项名（4–6 字） | 耗时 | 准入门槛（或熟手豁免） | 检定与风险代价 | 薪酬公式（便士）与原版技能成长 |
| :--- | :---: | :--- | :--- | :--- |
| **近岸撒网** | `(0:16)` | 运动 `D`（`>=280`，阴雨天 `+40`）或已掌管外海舢板 | 失败：网脚挂暗礁破口，鱼钱归零，`<<stress 5>><<tiredness 3>>` | `4 * (300 + 阶梯*60 + 运动/6 - 雨天50 + 渔船联动40)` + `<<athletics 2>>` |
| **攀外礁下竿** | `(0:18)` | 游泳 `D`（`>=260`）或已掌管外海舢板 | 失败：浪头拍滑磕破膝盖，断线丢钩，`<<pain 2>><<stress 6>>` | `4 * (480 + 阶梯*70 + 游泳/5 + 渔船联动50)` + `<<swimmingskill 2>>` |
| **夜钓外海** | `(0:20)` | 仅限夜间 + 已获配夜钓灯与头等摊位 | 需控管码头警觉度 `+4`，高收益无硬失败 | `4 * (620 + 阶梯*80 + 渔船联动60)` + `<<tending 2>>` |
| **刮鳞分筐** | `(0:15)` | 零门槛保底岗位（新手友好） | 零失败风险，夜间可降低警觉 `-5`，微增疲劳 | `4 * (240 + 阶梯*45 + 后厨联动30)` + `<<housekeeping 1>>` |

#### 4. 鱼档专属当班突发事件池（班次中/结算前实时穿插，非通用模板）
在 `MP Job Fish Shift` → `MP Job Fish Settle` 闭环中，除了节气水文（春汛银鲹、夏夜蓝绿荧光海、秋分大潮、冬日结冰栈桥），专门配备 **4 个鱼档独有互动事件**：
1. **【栈桥活蟹逃篓】**（`MP Job Extra Fish 1`）：刚卸船的活青蟹挣断草绳往栈桥缝爬。可选 **戴手套捉蟹**（运动/照料 `D`，得捉蟹赏钱 £15.20）或 **抄网兜回**（诡术/家政 `D`，得古铜渔具信物）。
2. **【风暴后的破网】**（`MP Job Extra Fish 2`）：大潮扯破主网眼，鱼贩赶着出船。可选 **穿梭引线补网**（家政/诡术 `D+`）或 **帮忙分拣压冰**（运动/照料 `D`）。
3. **【酒馆主厨加急挑刺】**（`MP Job Followup Fish`）：梅尔街酒馆急需去骨银鳕鱼柳。可选 **片出鱼柳**（照料/运动 `D`）或 **铺冰码齐**（家政/科学 `D`）。
4. **【栈桥临检与暗潮】**（`MP Job Fish DockCheck` 新增当班插曲）：港务巡查员或挑剔鱼商突然来翻看冰筐成色。可选 **掀开底冰验腮**（照料/科学检定，多拿品相溢价）或 **递上烟叶搭话**（魅力/诡术检定，平息盘问）。

#### 5. 失误、三次记过、停工与消过闭环
- **1 次失误（`$mpJobFishStrike == 1`）**：网破或断线，鱼贩把破网丢给你自己补。可在 `MP Job Punishment Fish 1` 选择 **绑好三十枚新钩**（照料 `D`）或 **把冰筐搬去冷库**（体魄 `8000`）消去记过。
- **2 次失误（`$mpJobFishStrike == 2`）**：分成下调（`$mpJobFishPenalty = 1`），暂停借用加固竿。可在 `MP Job Punishment Fish 2` 选择 **刷洗整条栈桥**（运动 `D+`）或 **替鱼贩守前半夜冷库**（意志 `C`）恢复分成。
- **3 次失误（`$mpJobFishStrike >= 3`）**：暂时停班（`$mpJobFishSuspended = 1`），鱼竿收回棚内。需在 `MP Job Punishment Fish 3` 完成 **潜下缆桩清缠网**（游泳 `C`）或 **一筐筐重分杂鱼**（照料 `D+`）方可复工。

### 样板 B：温泉桑拿房（`MP Job Spa` — 多瑙河街理疗浴场）

#### 1. 场景定位、真实入口与时段门控
- **挂载位置**：原版 `:: Spa`（多瑙河街水疗馆，`$location = "spa"`，`$outside = 0`）。
- **营业时段门控**：`08:00–22:00` 正常迎客；若在深夜或破晓（`< 8` 或 `>= 22`）前往，通过 `MP NotNow` 温和拦截（「浴场已放平池水熄灯落锁，乔丹让你白日再来当班」），彻底杜绝半夜三点还在正常接满堂浴客的违和感。
- **暴露度联动**：若玩家衣着暴露（`$exposed >= 1`），乔丹会先递来宽大浴巾让你围好再进池边；若玩家在**孤儿院浆洗房**已熟稔（`$mpJobLaundryLevel >= 2`）或在**河湾农场**种出香草（`$mpJobFarmLevel >= 2`），浴巾皂香与迷迭香蒸汽会带来额外减压与小费加成。

#### 2. 常驻人物与微故事递进
- **乔丹 / 神殿修士（领班）**：声音轻缓、行事严谨。从最初让你“先认清毛巾藤篮与铜灯位置”，到“在私汤木牌背面刻上你的缩写”、“把三号私汤铜钥匙交给你保管”，最后在更衣室门口给你留一杯压着字条的温茶。
- **退休歌剧女高音（常客）**：只在你当班时点名预约薰衣草药浴与肩颈推拿（`MP Job Followup Spa`），熟稔后会赠予歌剧院首演纪念银章。

#### 3. 班次动作设计（3 个差异化岗位 + 1 个当班特约护理）
| 选项名（4–8 字） | 耗时 | 准入门槛（或熟手豁免） | 检定与风险代价 | 薪酬公式（便士）与原版技能成长 |
| :--- | :---: | :--- | :--- | :--- |
| **替客人擦背** | `(0:18)` | 照料 `D`（`>=280`）或已掌管私汤铜钥 | 失败：毛巾未拧干淌湿客腰，遭投诉无薪，`<<stress 8>><<tiredness 3>>` | `4 * (700 + 阶梯*100 + 照料/4 + 浆洗联动40)` + `<<tending 2>>` |
| **池边引位调水温** | `(0:16)` | 美貌 `3000` 或 魅力 `D`（`>=280`）或已掌管私汤铜钥 | 失败：指错更衣室致客受凉，无小费，`<<stress 8>>` | `4 * (620 + 阶梯*90 + 魅力/4 + 农场香草40)` + `<<housekeeping 2>>` |
| **清理蒸汽房** | `(0:15)` | 零门槛保底岗位 | 零失败风险，蒸汽熏眼微增疲劳 | `4 * (420 + 阶梯*60 + 浆洗联动30)` + `<<housekeeping 1>>` |

#### 4. 桑拿房专属当班突发事件池
1. **【三号贵宾室精油瓶碎裂】**（`MP Job Extra Spa 1`）：客人进门前五分钟薰衣草精油瓶摔碎。可选 **湿布裹碎玻璃**（家政/诡术 `D`）或 **开窗铺毯调香**（照料 `D` / 意志 `C`）。
