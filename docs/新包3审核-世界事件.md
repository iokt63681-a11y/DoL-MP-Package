## 四、P0 集成 bug

### 1. `workicon` 未注册（25 处）

- world-events 用了 25 次 `<<workicon>>`。
- 本体没有这个宏，`mp.js` 的 `iconMap` 也没有。
- 结果：所有"帮忙/分拣/清理"类链接会报 `macro does not exist`，或者图标不显示。

修法二选一：

- 在 `mp.js` 的 `iconMap` 加 `workicon: "investigate"`（或 `"socialise"`）；
- 或把 25 处 `<<workicon>>` 改成现有的 `<<investigateicon>>` / `<<socialiseicon>>`。

### 2. 三个返回目标不存在

| 现在写的 | 本体实际 | 建议 |
| --- | --- | --- |
| `Hospital Courtyard` | 不存在 | `Hospital front` |
| `Swimming Pool` | 不存在 | `School Pool` 或 `School Pool Entrance` |
| `Sewers` | 没有同名 hub | 用 `$mpReturnPassage`，或退回 `High Street`/最近的合法街口 |

影响：点"离开/返回"会落到空 passage。

### 4. `mpAmbient` 缺 case

world-events 用了 `$location="pool"`、`"hospital"`、`"domus"`、`"high"` 等；`mpAmbient` 只有 `forest/docks/sea/temple/school/sewers` + default。

- `pool`、`hospital` 是室内，会拿到默认街景句；
- `domus`、`high` 是街道，default 勉强可以；
- 其他文件还会用到 `avery_mansion`、`underground`、`brothel`、`cabin`、`searocks`、`danube`。

建议加：

- `"pool"` → 泳池/蒸汽/瓷砖
- `"hospital"` → 消毒水/走廊/病房
- `"avery_mansion"` → 宅邸/吊灯/地毯
- `"underground"`/`"sewers"` → 管道/蒸汽/滴水
- `"brothel"` → 丝绒/香水/低语
- `"cabin"` → 木屋/炉火/兽皮
