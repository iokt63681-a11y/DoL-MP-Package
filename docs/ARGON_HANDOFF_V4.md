## 三、硬规则（必须继续遵守）

1. **一个 passage 只写一个瞬间**；多步骤拆 passage。
2. 选项写动作，不写结果/奖励/整条流程；链接标签不超过 12 个汉字。
3. 每个 passage 开头 `<<set $outside to 0或1>><<set $location to "...">>`；室内 0，室外 1。
4. `[nobr]` 必须加；不加会在正文里多出自动换行。
5. 返回目标必须存在；用 python 对照本体 HTML + 所有 mod twee 检查。
6. 有检查就有成功/失败和后果；失败不要扣现有钱，用 stress/tiredness/trauma/pain/失去线索/停优待。
7. `<<money 1200>>` = £12；奖励按任务基准和等级分档；一次性奖励用 `claimUniqueReward`。
8. 禁止复制正文、模板句、物件名填空、批量脚本改写。
9. 图标必须已注册；`$mpKnown` key 必须和 new-regions 对齐；新增 `$location` 必须有 `mpAmbient` case。
10. **不要显示 Lv / 等级 / 经验数字**；进度用叙事、道具、钥匙、称呼、熟客行为表达。
11. **不要写打工失败扣存款**；失败 = 白干/丢小费/材料损失/停优待/停班。
12. 三级惩罚的结构要保持：第一次警告，第二次停优待，第三次短暂停班并可清除。
