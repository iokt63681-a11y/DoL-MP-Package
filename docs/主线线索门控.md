# 主线 `$mpClues` 门控改写

> 对象：`mp-main-and-collection-quests.twee`
> 结果：12 章 hub 改成"当前场景 + NPC 提示 + 线索 flag"，不再旁白一次性剧透整条链。

## 一、改之前

- `MP Main Story Eclipse Hub` 一个 passage 里塞了 12 个阶段；
- 每个阶段旁白直接把下一步地点写出来，还列出整条链（钟表铺、天文翼楼、地下修道院、雾角灯塔岛……）；
- 12 条链接都是"利用赤道仪折射星光定位修道院坐标"这种长动作；
- 没有任何 `$mpClues` 门控，世界事件/grand 写的 30+ 个线索 key 主线不读。

## 二、改之后

- 12 个阶段各 3～4 句，只写当前场景；下一步由 NPC 说出来：
  - 罗宾 → 高街石墙的旧账册；
  - 塞拉 → 天文翼楼的赤道仪；
  - 诺艾尔 → 神殿地下的灰烬藏经阁；
  - 约旦 → 多瑙河温室；
  - 温室侍者 → 黑铁货运站；
  - 码头工 → 森林石环；
  - 伊甸 → 峭壁假面拍卖会；
  - 布莱尔 → 旧钟塔机括城；
  - 守夜人 → 雾角灯塔；
  - 灯塔顶层 → 终局。
- 每条推进链接都写 `$mpClues["main_eclipse_N"]`，并推进 `$mpMainStoryEclipse`；
- 每个阶段块都有对应的 `$outside` / `$location`（高街、钟表铺、学校、神殿、温室、码头、森林、夜场、地下、下水道、海礁、灯塔）；
- 链接标签最长 7 字（撬开基石 / 校准赤道仪 / 去藏经阁 / 潜入货运站 / 去石环 / 潜到泉底 / 混进后台 / 校准主阀 / 收下油布包 / 登塔 / 打开铁柜）；
- 删掉了"钟表铺、天文翼楼、地下修道院与雾角灯塔岛"这类一次性剧透；
- `MP Main Story Eclipse Resolve` 改成短结果页：只写"你把第 N 章物证收好"，不列整条链。
