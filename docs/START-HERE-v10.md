# START HERE（dev12）

1. 解压 `DoL-MP-v1.2.0-dev12-Full-Package.zip`。
2. 双击 `start-game.bat`。
3. 进游戏后按 `Alt+M` 打开 Mod 管理器，关闭安全模式。
4. 移除旧的 DoL-MP，添加 `mods/` 下的：
   - `DoL-MP-v1.2.0-dev12.mod.zip`
   - `ModI18N-0.5.12.13-chs-1.0.1a.mod.zip`
   - `GameOriginalImagePack-0.5.12.13.mod.zip`
5. 重新载入，读档或开新档。

升级前先导出存档备份。
