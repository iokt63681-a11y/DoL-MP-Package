## 本批最重要的四条

1. **先修结构，再写内容**：98 段奖励档位 `if` 绑定、20 段 `_first` 绑定、6 段双 `<<else>>` 是本批最高优先级；写完必须跑栈式 if/else 检查。
2. **失败不是发奖段**：失败只给重试/退出与具体代价，不推进、不发钱、不写成功文案。
3. **两个动作要真的不同**：不同技能、不同成功文本、不同失败代价、不同去向；不能只差 `stress/tiredness` 和一个没人读的线索键。
4. **文案从场景长出来**：选项点名的物件必须在正文出现；时间/季节词必须有 `Time.*` / `Weather.*` 门控或中性化。
