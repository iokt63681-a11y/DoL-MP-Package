# 零工深度对标矩阵（V34）

原版没有独立的「面包房」零工；本项目的 `MP Job Bakery` 是目前最完整的一条（入口/时段/班次/结算/进度/专属插曲都有）。V34 以它和原版 `Cafe`、`Farm`、`Docks` 的班次结构为基准，把 12 条零工都拉到同一精细度。

## 目标维度（每条零工都要有）

| 维度 | 目标 |
|---|---|
| 入口 | 真实街区/店铺，营业时段门控，打烊分支 |
| 班次动作 | 4 个：2 个技能路线、1 个资历路线、1 个无门槛保底 |
| 专属插曲 | 5 个，每天最多触发 1 次，各有 3 个选项 |
| 常客 | 3 名具名常客，各有 1–2 段回调台词 |
| 小故事 | 1 条 3 阶段的连续小剧情，和资历/季节绑定 |
| 季节/天气 | 春/夏/秋/冬 + 雨/雪 各至少 1 句专属变化 |
| 进度 | 5 个叙事节点（工具、钥匙、称呼、熟客、责任），不显示 Lv/等级 |
| 失败 | 3 次记过 → 停工 → 说理/补救 → 复班 |
| 跨店 | 至少 1 条上游供货、1 条下游订单 |
| 经济 | 工资公式 + 首通里程碑 + 小费；失败零发奖 |
| UI | 单页 ≤5 项，标签 4–8 字，图标唯一 |

## V34 交付顺序

1. **框架先行**（Argon 先做）
   - 统一的零工班次/插曲/进度写法，抽成可复用 widget 或固定模板，避免 12 份复制粘贴。
   - 插曲触发表：每条零工的 5 个插曲、每日键、触发条件、选项、奖励键集中登记。
   - 进度节点表：5 个节点的叙事条件与解锁物。
2. **P0/P1 内容**：面包房（基准复核）、咖啡馆、鱼档、桑拿、农场各补 4 个插曲 + 3 阶段小故事 + 2 名常客 + 季节变化。
3. **P2/P3 内容**：其余 7 条按同一模板补齐。
4. **验收**：矩阵每一格从「缺」变「有」，并跑全库结构/图标/奖励/时段检查。
