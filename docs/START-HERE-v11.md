# START HERE（dev13）

1. 解压 `DoL-MP-v1.2.0-dev13-Full-Package.zip`。
2. 双击 `start-game.bat`。
3. 进游戏后按 `Alt+M` 打开 Mod 管理器，关闭安全模式。
4. 移除旧的 DoL-MP，添加 `mods/` 下的：
   - `DoL-MP-v1.2.0-dev13.mod.zip`
   - `ModI18N-0.5.12.13-chs-1.0.1a.mod.zip`
   - `GameOriginalImagePack-0.5.12.13.mod.zip`
5. 重新载入，读档或开新档。

升级前先导出存档备份。

## 本版要点

- 72 个 twee / 2,155 段；8 个区域随机池独立拆分。
- 选项标签中位数 4 个汉字、最长 8；重试 `再试一次`，出口 `离开`/`返回<短地名>`。
- 失败分支不再发钱/写线索；观察选项不再白给钱或古物。
- 新地点改为发现制：属性/线索、街区偶遇、NPC 提到后才会出现，入口在地点栏「新地点」。
- 打工收入对齐原版：£12–£60/班。

详见 `更新说明-v1.2.0-dev13.md` 与 `docs/argon-dev13-audit.md`。
