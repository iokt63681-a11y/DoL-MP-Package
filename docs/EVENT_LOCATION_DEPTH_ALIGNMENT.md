# DoL-MP 长线事件 / 世界机制 / 地点深度对齐设计

> 调研来源：DoL 0.5.12.13 源码（16,087 passage）、中文 wiki 及递归抓取的 372 个页面（主线任务、咖啡馆活动、农场袭击、贝利的付款、神殿/晋升、凯拉尔绑架、游戏机制、地点分类、海滩、脱衣舞俱乐部等）。
> 结论：原版的长线不是“多写几段”，而是**里程碑计数器 + 可见的世界状态 + 多结局 + 跨系统咬合**。我们的长线目前是 7 段模板链，地点是事件池，机制只有警戒/火光/古物三个孤岛。

### 1.1 长线的五个硬指标

1. **可见计数器**：钱、面包数、田地数、恩典、怀疑度、印象——玩家随时知道进度。
2. **不可逆的世界状态**：装修、涨价、解锁地点、NPC 迁移、商店关门。
3. **多结局**：至少 2 条，且后果写进后续事件池。
4. **跨系统咬合**：贝利 ↔ 农场；咖啡馆 ↔ 艾弗里/奎恩/格威岚；神殿 ↔ 悉尼；凯拉尔 ↔ 罗宾/惠特尼。
5. **失败不是 Game Over**：软坏结局、惩罚轮换、下周重试。

### 1.2 原版世界机制工具箱

| 机制 | 关键设计 | 可借鉴点 |
| --- | --- | --- |
| 世界腐化（软/硬） | 每周日软腐化 += 硬腐化；玩家行为可推高/压低；神殿雕像可见 | 世界状态要可见、可推拉、有周节奏 |
| 名声（11 类） | 200 点起被认出；不同名声解锁不同事件；绰号 | 多轴声望，正负都有用 |
| 安全屋（安全/风险/监禁） | 床、衣柜、镜子、淋浴、设置；监禁类剥夺设施 | 地点深度不必靠剧情，靠设施与状态 |
| 软坏结局（8 处） | 困住但可逃；逃跑需要准备 | 失败给出路，不给死档 |
| 古董/博物馆 | 收集→鉴定→展出→活跃度→遇袭事件 | 收藏型长线 + 地点状态 |
| 转化/特质 | 长期身体状态，改变事件与对话 | 玩家自身也是长线容器 |
| 战斗变体 | 跟踪遭遇、集群、机器、搏斗 | 长线里插入不同战斗节奏 |
| 成就 | 数百个，给点数与硬币 | 长尾目标，引导探索 |

## 二、我们的现状（dev16 实测）

| 项 | 数量 | 结构问题 |
| --- | --- | --- |
| `MP Main` | 5 段 | 只有“日蚀”4 线索链，无世界状态 |
| `MP Grand` | 112 段 = 16 条 × 7 段 | 每条固定 6 步 + Resolve，步内是门控动作，无多结局 |
| `MP Quest` | 111 段 = 15 条 × 7 段 | 同上；`Bailey Rebellion` 仅 5 段 |
| `MP Region` | 572 段 | 区域事件池，无地点进度 |
| `MP Job` | 450 段 | 12 条零工，有班次无行业长线 |
| `MP Festival` | 109 段 | 节日内容多，但与世界状态不联动 |
| 世界状态 | `mpAlert`、`mpLight`、`mpAntiquesUnappraised` | 三个孤岛，互不咬合，无周节奏 |
| 地点 | Region Hub / Story Hub | 有入口与事件，无设施、无升级、无日程层 |

**核心差距**：我们有很多“事件”，但没有“世界”；有“进度变量”，但没有“可见状态”；有“结局文本”，但没有“结局后的世界”。

## 三、原创长线设计（四个）

### 3.1 主线：雾潮 Fog Tide（世界状态长线）

- **状态**：`$mpFogTide` 0–7，每周推进 1 格（可配置 5–7 天）。UI 在城镇/码头/森林页顶部显示潮位。
- **表现**：潮位越高，雾越重——部分小路关闭、商店提前打烊、NPC 日程缩短、夜间遭遇池替换、码头能见度下降、森林出现雾中事件。
- **推拉**（四条杠杆，每条都能双向）：
  1. **点灯**：消耗灯油，在森林/码头点亮信标，−1 潮位；灯油价格随潮位上涨，形成经济压力。
  2. **测潮**：塞拉/维斯的仪器与潮汐表，−1 潮位；需要零件与整点窗口。
  3. **神殿净化**：消耗恩典，−1 潮位；恩典低时无法进行，形成信仰取舍。
  4. **行会契约**：花钱/材料雇人清障，−1 潮位；会推高地下行会声望。
- **反噬**：每次压下潮位，会在另一处 +1 压力（例如点灯让灯油短缺、契约让码头警戒上升）。
- **派系反应**：码头（想借雾走私）、行会（想囤货）、神殿（想封港）各有立场；玩家选择影响结局。
- **潮位 7 结局**：封港（安全但经济重创）/ 撤离（人口流失、商店关闭）/ 与潮议价（解锁雾中市场，长期高风险高收益）。
- **接入**：`mpAlert`（雾中警戒）、`mpLight`（信标火光）、天气、区域日程、零工价格。

### 3.2 经济政治：十二行会 Guild Assembly

- **状态**：12 条零工各有 `$mpGuildStanding[<job>]` 0–100；四大 bloc：码头、工匠、服务业、地下。
- **循环**：完成班次/零工任务涨对应行会声望；接私活涨地下声望但掉行会声望。
- **季度大会**：每季一次，三项议案投票（最低工资、宵禁、码头通行、市场税）。玩家用声望/人情/贿赂拉票。
- **世界后果**：议案通过后改工资倍率、商店价格、宵禁时段、区域通行、节日内容。
- **结局**：改革派（工资涨、地下受压）/ 保守派（物价稳、地下繁荣）/ 分裂（各行会独立，价格波动）。
- **接入**：12 条零工、商店、节日、码头通行、NPC 态度。

### 3.3 债务：账本 The Ledger

- **状态**：`$mpLedger` 记录贝利账本、受保护孤儿名单、每周应付、逾期次数。
- **循环**：每周应付随受保护人数上升（1 人 +100%，2 人 +200%，3 人 +300%）；可付钱、打退、伪造账本、偷账本。
- **三条救援支线**：分别对应三个孤儿（可复用现有 NPC 或新 NPC），每条有独立营救地点与后果。
- **世界后果**：孤儿院伙食/供暖/门禁变化；贝利打手强度；农场袭击是否被加强。
- **结局**：付清（孤儿院改善）/ 夺账（贝利失势，地下接管）/ 逃离（孤儿院衰败，孤儿流散）。
- **说明**：这是现有 `MP Quest Bailey Rebellion` 的扩展，不是推倒重来。

### 3.4 神殿：裂缝 Temple Schism

- **状态**：`$mpGrace`（恩典）、`$mpTempleOrder`（正统/改革）、`$mpTempleRites`（仪式进度）。
- **循环**：加入试炼（火焰 7 步）→ 杂役与告解 → 晋升守夜/蹈火 → 发现两派。
- **选择**：正统（保留恩典津贴与庇护，封港倾向）/ 改革（开放回廊，削弱津贴，与码头和解）。
- **世界后果**：神殿服务（治疗、庇护、津贴）、回廊准入、悉尼/诺艾尔的去留、雾潮净化效率。
- **结局**：正统胜（神殿强、地下弱）/ 改革胜（神殿开放、经济活）/ 分裂（两派并存，玩家兼任调停）。

## 四、原创机制（四个，可独立落地）

1. **雾潮时钟**：周节奏、可见、可推拉、有反噬。与现有 `mpAlert`/`mpLight` 咬合。
2. **信誉板 Standing Board**：四派系 0–100，互相拉扯；商店价格、通行、服务、结局都由它驱动。
3. **安全屋网络 Safehouse Network**：6 个安全屋，可升级床铺/储物/工作台/信标；有维护费与被贝利发现的概率；安全屋之间可快速移动（消耗时间）。
4. **线索板 Case Board**：线索→假设→指认；用于林恩旧案、神殿裂缝、雾潮调查；指认错误会掉信赖并关闭部分结局。UI 用现有菜单页实现，不新增图片。

## 五、地点深度（六个重点地点）

每个地点都按三层设计：**表层（入口/活动）→ 中层（工作/日程/循环）→ 深层（进度/季节/世界状态）**。

### 5.1 旧港码头 Docks

- 入口：白天自由；夜间需码头通行证或维斯引路。
- 人员：维斯、Wren、鱼贩、夜班船工。
- 表层：钓鱼、卸货、夜航、仓库探索、酒馆。
- 中层：码头零工（4 种工序）、夜航委托（货种/航线/船员）、警戒与盘查。
- 深层：船只三级升级、仓库网络解锁、雾潮影响能见度与航线、行会投票决定通行税。
- 季节：冬季结霜（甲板滑倒）、雾季（能见度）、风暴（停航）。

### 5.2 高街 High Street

- 入口：自由；宵禁后需通行或躲藏。
- 人员：塞拉、行会执事、商店老板、巡夜人林恩。
- 表层：钟表铺、裁缝铺、杂货、咖啡、银行。
- 中层：店铺声望、订单、行情（价格随行会议案波动）、扒手与巡逻。
- 深层：行会会馆（投票、委托）、雾潮期间商铺提前打烊、节日游行改变人流与事件池。
- 季节：集市日、灯会、冬市。

### 5.3 森林 Forest

- 入口：白天自由；夜间需火光或向导。
- 人员：阿什、伊甸（重叠）、黑狼（领地）。
- 表层：采集、打猎、迷路、野兽。
- 中层：巡林三路线（阿什）、营地建设、火光资源、雾中事件。
- 深层：七盏灯网络、雾潮推进的主战场、狼群领地状态、与伊甸小屋的物资往来。
- 季节：雾季、雪季、兽群迁徙。

### 5.4 学园 School

- 入口：上学日；假期闭校。
- 人员：诺艾尔、Mason、Leighton、学生 NPC。
- 表层：上课、考试、食堂、图书馆、社团。
- 中层：成绩与课程（影响零工与考试）、社团活动、霸凌事件、科学展。
- 深层：学期进度、考试排名、舞台剧、与神殿/行会的联合活动、雾潮停课事件。
- 季节：开学/假期、考试周、文化祭。

### 5.5 神殿 Temple

- 入口：随时祈祷；加入需纯洁试炼；晋升需恩典满。
- 人员：约旦、主教、修士修女、悉尼（若同行）。
- 表层：祈祷、弥撒、告解、杂役。
- 中层：恩典、月度津贴、火焰试炼（每周）、告解室工作。
- 深层：晋升回廊、六臂神像（世界状态读数）、两派裂缝、雾潮净化。
- 季节：周日弥撒、节庆、封港期。

### 5.6 孤儿院 Orphanage

- 入口：自由；贝利在办公室时需小心。
- 人员：贝利、罗宾、其他孤儿、凯拉尔（可选）。
- 表层：卧室、阁楼、花园、浴室、客厅。
- 中层：贝利付款、杂务、孤儿互动、夜间事件。
- 深层：账本长线、孤儿保护名单、孤儿院状态（伙食/供暖/门禁）、雾潮期间的收容压力。
- 季节：圣诞节、万圣节、寒冬供暖。

## 六、实施拆分（建议）

- **V38-A（P0）**：雾潮时钟 + 点灯/测潮两条杠杆 + 码头/神殿/孤儿院三个地点的三层框架。
- **V38-B（P1）**：行会声望板 + 季度大会 + 高街/森林/学园三个地点。
- **V38-C（P2）**：账本长线（三条救援支线）+ 安全屋网络 + 线索板。
- **V38-D（P2）**：神殿裂缝、雾潮结局、季节变体与价格联动。

## 七、验收标准

- 每条长线有：可见计数器、≥3 个阶段、≥2 个结局、≥1 个不可逆世界状态、≥2 个跨系统咬合点。
- 每个地点有：入口门控、≥4 项活动、1 条工作/班次、≥6 个循环事件、1 个进度状态、1 个季节变体。
- 状态必须存档安全、联机同步、UI 可见（菜单页即可，不新增图片）。
- 失败给出路：软坏结局/惩罚/下周重试，不做死档。
- 结构：断链 0、重名 0、宏栈 0、失败分支不发钱、`boot.json`/`manifest.md` 同步。
