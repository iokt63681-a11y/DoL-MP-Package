# DoL-MP NPC 深度对齐设计（原版解剖 + 我们的差距 + 原创方案）

> 调研对象：DoL 0.5.12.13 汉化版源码（16,087 个 passage）、中文 wiki 罗宾/悉尼/凯拉尔/惠特尼/伊甸/艾弗里/艾利克斯/格威岚/黑狼/巨鹰页面。
> 结论一句话：**原版的深度不是“字数多”，而是每个恋爱 NPC 都有一条只属于他/她的状态轴、一套专属循环、一条会改变世界的个人任务。我们的 6 个常驻 NPC 目前是同一套模板实例化了 6 次。**

### 1.3 原版“深度”的七个可复用手法

1. **一个专属轴决定行为分层**：罗宾自信 0–19/20–79/80–100 三档，连“谁在关系里主动”都会变；悉尼纯洁 50/20 两个阈值把整个人格切换成两套。
2. **专属循环必须带取舍**：罗宾给钱会让存款见底、提前卖游戏机；悉尼保持纯洁和高性欲互相拉扯；伊甸顺从换自由但累积斯德哥尔摩。
3. **个人任务改变世界状态**：罗宾被卖到码头后，房间空了、柠檬水摊消失、后续惩罚全变；凯拉尔被放逐后从监狱才能捞回来。
4. **数值不是单向涨**：悉尼可以重新净化再腐化；罗宾自信可由玩家主动让渡主导权来升降。
5. **同一事件按状态重写**：低自信罗宾躲在你身后，高自信罗宾会挡在你前面；这不是加一段文本，是换一套选项。
6. **节日是独立任务链**：万圣节要提前 10 天买服装，服装影响当天所有对话；圣诞节礼物按价格/性别/异装分支。
7. **NPC 互相咬合**：罗宾-惠特尼霸凌、悉尼-惠特尼偷书、凯拉尔嫉妒罗宾、伊甸-格威岚营救。

## 三、设计原则（原创性 + 原版深度）

1. **学结构，不抄内容**：只复用“一轴 + 一循环 + 一任务 + 一节日 + 一约会 + 关系网”的骨架，不复制罗宾的自信、悉尼的纯洁、凯拉尔的嫉妒。
2. **每个 NPC 的轴必须长在他/她自己的身份上**：守林人谈火种，守夜人谈街区信赖，画师谈缪斯，标本学徒谈共生，修表师谈节律，船长谈契约。
3. **循环必须有代价**：做这件事会关掉另一件事；数值要能升也能降。
4. **任务必须改变世界**：至少两种结局，其中一种会让 NPC 离开原位、迁移到新地点或改变日程。
5. **同一事件按轴分层重写**：低/中/高档不是换一句台词，而是换一组选项和结果。
6. **节日做成独立小任务链**：提前准备物、当天分支、事后余波。
7. **接入现有系统**：mpAlert（警戒）、mpLight（火光）、古物、信物、零工、区域池、节日表、联机同步。

## 四、六个 NPC 的原创方案

### 4.1 阿什（守林人）— 火种 Ember

- **身份**：森林灯道的守灯人，负责七盏引路灯与迷路者的救援。
- **专属轴**：**火种 0–100**。不是好感，是“老林把多少路交给你”。高火种时雾里会出现引路火光；低火种时夜林会把你引回原地。
- **专属循环：巡林三选一**。每日在“北坡兽径 / 河湾雾滩 / 废祠石阶”选一条；每条有 1 个事件 + 1 种材料，选了就关掉另外两条。材料用于**营地建设**（信号火 / 晾晒架 / 石棚），每级永久改变森林夜间事件与救援概率。
- **分层行为**：火种 <30 阿什只谈路线；30–69 会分你半块干粮、教你辨兽迹；≥70 会在雾里牵着你走，说出七盏灯的来历；≥90 触发“把最后一盏灯交给你”。
- **个人任务：第七盏灯**。灯网熄灭、一名巡林人失踪。两条结局：
  - 重燃七灯：阿什留下继续守林，森林夜间安全，火种上限 100；
  - 取走最后一枚火种：阿什离开森林成为可同行同伴，森林变成高危区，火种转为战斗增益。
- **节日：雾季守夜**（每年雾季一夜）。守灯/巡路/陪阿什三种选择，影响火种与森林 NPC 生死。
- **约会**：溪谷夜钓（雨天有涨水分支）、树冠观星（晴天）。
- **日程**：森林石径（6–12）、河湾营地（12–18）、废祠（18–23）。
- **关系网**：伊甸（林地重叠）、黑狼（领地）、维斯（灯油走私）。
- **说话特征**：短句、先看天色再回答、把关心说成路线建议。

### 4.2 林恩（守夜人）— 街区信赖 Watch

- **身份**：宅邸街—多姆斯街的夜班守夜人，兼职教人防身。
- **专属轴**：**街区信赖**，按街区分别记 0–100（宅邸街 / 多姆斯街 / 高街）。高信赖降夜间警戒、开捷径；低信赖增加伏击与盘查。
- **专属循环：夜巡案件板**。每晚选一个街区，抽 1 张案件卡（扒手 / 醉汉 / 家暴 / 失窃 / 可疑货箱 / 旧案线索）。三种处理：执法（+法理）、人情（+人情）、武力（+疼痛风险）。法理/人情是隐藏双向轴，影响 Bailey 与 Whitney 的反应。
- **分层行为**：<30 只谈巡逻；30–69 会留热姜汤；≥70 教你防身（解锁战斗选项）；≥90 让你替他值一次班（触发旧案）。
- **个人任务：旧案**。林恩旧搭档的死被压成意外。两条结局：
  - 翻案：林恩脱制服，开一间夜间武馆，成为可同行同伴；
  - 压案：林恩升任队长，街区安全但人变冷，部分亲密选项永久关闭。
- **节日：冬夜火盆**。为殉职守夜人守夜；带酒/带花/带人三种选择。
- **约会**：屋顶巡夜、夜市小吃。
- **日程**：宅邸街岗棚（16–24）、多姆斯街巡逻（0–4）、武馆/岗棚（4–7，睡后）。
- **关系网**：惠特尼（惯犯）、贝利（施压）、礼顿（校界）。
- **说话特征**：先报时间地点、少用形容词、承诺必兑现。

### 4.3 莫奈（画师）— 缪斯 Muse

- **身份**：康努达图斯街阁楼画室的画师，接贵族与商人委托，也画不肯卖的画。
- **专属轴**：**缪斯 0–100**。你在她作品里的分量。高缪斯会解锁“以你为原型的画”，挂在画室并改变后续场景；低缪斯她的画转向别处。
- **专属循环：画室委托**。每周 3 张委托（肖像 / 风景 / 禁画），选主题、配色（暖 / 冷）、交期。成品是**持久物件**：可卖钱、可送礼、可留在画室改变对话；禁画会带来贵族丑闻风险。
- **分层行为**：<30 只谈材料；30–69 让你做助手；≥70 让你做模特；≥90 画你但不肯卖。
- **个人任务：未完成的壁画**。市政厅委托的大壁画。两条结局：
  - 完成：莫奈成名离镇，画室留给孤儿院，定期寄信；
  - 覆画：她留下开免费画室，失去赞助，缪斯上限 100 并解锁“共同署名”。
- **节日：海雾画展**。按缪斯与配色评分，获奖改变她在镇上的地位。
- **约会**：露台写生（晴天）、画廊夜游（有艾弗里撞见风险）。
- **日程**：画室（10–16）、露台（16–20）、夜市找灵感（20–23）。
- **关系网**：艾弗里（赞助人）、格威岚（颜料）、塞拉（画框）。
- **说话特征**：先形容颜色再说话、把请求说成构图、用“光”作比喻。

### 4.4 诺艾尔（植物学徒）— 共生 Symbiosis

- **身份**：学园标本室的学徒，替 Harper 试草药，自己偷偷配茶。
- **专属轴**：**共生 0–100**。诺艾尔的药草菌群与你的身体适应程度。高共生解锁更强药效与专属茶；过高会出现耐受与副作用。
- **专属循环：标本图鉴 + 试药**。采集各区域的植物补图鉴，每完成一页解锁一种茶/药膳；温室药圃每日浇水/遮光。试药会给一个**持久小特质**（睡眠更好 / 疼痛 -1 / 体味影响 NPC）和一个副作用；耐受度上升后必须换配方。
- **分层行为**：<30 只谈标本；30–69 给你安神茶；≥70 让你试新配方；≥90 把母株的事告诉你。
- **个人任务：枯萎的母株**。学园唯一母株将死。两条结局：
  - 救活：诺艾尔留校，获得独立标本室，药圃升级；
  - 炼药：母株制成特效药，诺艾尔被开除，跟你走，解锁稀有药方。
- **节日：花期祭 / 冬至药膳**。提交一株花或一道药膳，按图鉴完成度评分。
- **约会**：花房夜谈、野外采药（雨天有滑倒与稀有菌分支）。
- **日程**：标本室（7–12）、花房（12–17）、公园采集（17–20）。
- **关系网**：Harper（医院）、Mason（老师）、伊甸（稀有草药）。
- **说话特征**：先问身体再问来意、把关心说成配方、紧张时数花瓣。

### 4.5 塞拉（修表师）— 节律 Cadence

- **身份**：高街钟表铺的修表师，替人修复古物与怀表，父亲留下的一只表始终停着。
- **专属轴**：**节律 0–100**。你是否守时、是否在她安静工作时陪着。迟到/爽约会掉，准时和安静陪伴会涨。
- **专属循环：修复委托**。每周 3 只钟表，每只是一个零件+技能的小谜题；成功修复揭示一段她父亲的日记；失败掉信誉。修好镇钟后解锁“看时刻表”能力。
- **机制：整点窗口**。部分事件只在 6:00 / 12:00 / 18:00 整点出现；怀表信物可查看 NPC 日程，每日一次“让时间慢一拍”（重开一个选项）。
- **分层行为**：<30 只谈修表；30–69 给你留红茶；≥70 让你上阁楼；≥90 说出停摆怀表的事。
- **个人任务：停摆的怀表**。两条结局：
  - 修好：她与父亲和解，留下，节律上限 100，钟表铺扩成二层；
  - 不修：她离镇寻父，把怀表留给你（每日一次时间回溯），铺子由你代管。
- **节日：新年钟声 / 冬至长夜**。整点触发，按节律分层。
- **约会**：钟楼看日落、深夜修表。
- **日程**：钟表铺（8–15）、阁楼工作间（15–19）、高街散步（19–21）。
- **关系网**：古物系统、莫奈（画框）、维斯（走私零件）。
- **说话特征**：用时间量词、回答前先看表、把情绪说成误差。

### 4.6 维斯（夜航船长）— 契约 Tide

- **身份**：旧港夜航船长，跑暗市货、也偷偷运药和人。
- **专属轴**：**契约 0–100**。码头夜班船工对你的认可。接单、守信、按时交货会涨；毁约、被查、弃货会掉。
- **专属循环：夜航委托**。选货（药 / 私货 / 人）、选航线（外礁 / 暗渠 / 雾港）、选船员。潮汐与天气影响结果；每单涨契约、涨警戒（接 mpAlert）、给钱，并推动“道义”隐藏轴。船只可升级（货舱 / 帆 / 灯）。
- **分层行为**：<30 只谈水路；30–69 让你搭船；≥70 让你进底舱；≥90 说出“最后一票”。
- **个人任务：最后一票**。两条结局：
  - 跑完：维斯还清债，洗白成港务长，码头稳定但更腐败；
  - 凿沉：维斯被追捕，成为可同行同伴，码头失序，开出新的走私事件。
- **节日：海雾节 / 冬至返航**。按契约与道义分层。
- **约会**：夜航看灯、荒岛露营（潮汐窗口）。
