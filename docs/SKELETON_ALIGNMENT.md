# 骨架对照：DoL 原版 vs DoL-MP（dev45 → v45 交付）

> 结论：**我们做的是「中央菜单 + 线性任务链」，DoL 做的是「地点场景 + 班次/事件页 + 条件插曲」。**
> 门槛、失败锁、一次性结局补上了，但骨架还是 mod 的骨架，不是 DoL 的骨架。
> 证据来自 `vanilla-passages.twee`（16,087 段）与 `VANILLA_DESIGN_NOTES.md`。

---

## 1. 一个工作日的对照

### 原版：`Ocean Breeze`（地点页）

```
你走进咖啡馆 → 当前天气/营业时段的一句话场景描述
→ [如果条件满足] 自动插入一段 NPC 小事件（Sam 提价、Gwylan 的海鸥盘、Robin 来访）
→ 动作入口：Work as waiter (1:00) / Eat / Leave
```

点 `Work (1:00)` 进 `Ocean Breeze Work`：

```
班次页：
  1. 先按条件插入当天的插曲（Gwylan 的盘子 / Robin 来店）
  2. 没有插曲 → <<cleareventpool>> + <<addinlineevent>> ×N + <<runeventpool>> 抽一件
  3. 抽到「端盘子」→ 直接给两个动作：
       稳妥：Take multiple trips
       冒险：Balance the plates on your shoulders（检定，成功小费+，失败摔盘）
  4. 结果直接写在选项里，接着 <<pass 1 hour>>，Next 回咖啡馆
```

**关键**：事件不是按钮，是班次本身的内容；结果不跳页；一小时一个班次，你想干第二小时就再点一次。

### 我们现在：`MP Loc Forest Hub`

```
场景描述 → 9 个功能按钮：
返回林缘 / 探索森林表层 / 深入森林中层 / 潜入森林深层 /
观测季节异象 / 查看四季活动 / 查看季节转化钩子 / 更多日常
```

点「探索森林表层」→ `MP Loc Forest Surface` → 再点「林缘路标修补 (0:10)」→ `MP Loc Forest Event 1` → 选项带 (0:12) → 内嵌结果或跳 `Event 1 Result` → 再点返回。

**差别**：
- 我们的地点页是功能索引，原版的地点页是场景。
- 我们的「事件」是独立页；原版的事件是班次里抽出来的一段。
- 我们的动作是 0:10–0:20 的碎片；原版是 1:00 的班次 + 5–10 分钟移动。
- 我们的选项文案是「探索森林表层 / 深入森林中层」，原版是「Work / Talk / Leave」。

## 2. 八个维度的逐项对照

| 维度 | DoL 原版 | 我们现在 | 要改成什么 |
| --- | --- | --- | --- |
| 地点入口 | 街道 → 店铺；店铺页直接给动作（`Work (1:00)` / `Ask for work` / `Leave`） | 地点 Hub 8–9 个功能按钮，再进表层/中层/深层 | 地点页 ≤6 个动作，删「表层/中层/深层」这层菜单；层级用场景描述 + 条件链接自然体现 |
| 事件触发 | 班次内 `eventpool` 按权重抽；条件插曲（天气/季节/熟客）动态入池 | Hub 顶部 `mpXxxEventRoll` 随机弹一条；事件是独立页 | 随机事件并入「班次页」，不放在地点 Hub 上 |
| 结果页 | 结果写在选项内或同页，随后 `Next` 回地点 | 大量 `Event N Result` 独立页，选完再多一跳 | 取消独立 Result 页；结果进选项或同页 `<<replace>>` |
| 时间片 | 工作 1:00；移动 0:05–0:10；吃饭 0:20 | 每个动作 0:10–0:20，连点几次过一天 | 工作类统一 1:00；短动作 0:05–0:20；一天应该「做一两班就过去」 |
| 选项文案 | 动作短语：Work hard / Slack off / Take multiple trips / Next | 系统短语：搬煤加固梁 / 推进外礁初阶 / 深入二季的四至七 | 全部改成动作；时间标签只出现在班次/移动上 |
| NPC 线 | 日程函数定位 + 随机遭遇 + 关系门槛解锁特殊场景；没有线性任务 | `MP NPC Ash Deep Hub` → `Deep Quest 1..4C`，7–9 步直线 | 删线性 Quest 链；改成「日程 + 遭遇 + 门槛场景」；关系值解锁的是**场景**，不是任务步骤 |
| 失败 | 当场扣钱/关系/体力，同一班次继续；严重失败才 Bad End | `setback = Time.days + 2` 锁两天，不能重试 | 普通失败只扣代价 + 当天不能重试同一动作；两天锁只留给严重失败 |
| 结局 | 世界状态由长期条件累积（名声、恩典、派系席位），不是「点两个选项」 | `$mp<Name>Ended` 一次性结局，两个选项二选一 | 结局保留一次性，但触发要改成「累积条件 + 一个不可逆动作」；不要两击直达 |

## 3. 文案上的具体差别

原版（`Ocean Breeze Work`）：

> You are serving tables. A plate of seagull food sits unattended near the register.
> You look around. No one seems to be paying it any mind.
> [Take it to him]

我们（`MP Loc Orphanage Event 9` 压缩前）：

> 斜屋顶把阁楼的光压得很暗……你蹲下去看，箱盖侧面刻着几行歪斜的小字……
> 你可以先……也可以……还能……

问题：
1. **「你可以……也可以……还能……」是菜单导语**，原版不这么写；原版用场景把选项逼出来。
2. **选项重复正文信息**（正文说撬锁，选项再写「撬开锈铜锁」），原版选项短、动作先行。
3. **系统词进正文**（「进度」「阶数」「台账」），原版用世界内的词（「水尺」「灯簿」「案卷」）。
4. **段落过长**：原版一段 1–3 句；我们 5 段 500 字。

## 4. 下一轮骨架规则（给 Argon）

### 4.1 页面类型只有四种

1. **地点页**（街道/店铺/林地入口）：1–3 句场景 + 3–6 个动作 + 条件插入的 NPC/天气句。不列功能索引。
2. **班次页**（工作/巡林/守夜）：进入即 1:00；先条件插曲，再 eventpool；每条分支结果内嵌；结束 `<<pass 1 hour>>` + 回地点。
3. **场景页**（NPC 门槛场景/地点特殊事件）：1–3 句 + 2–4 个动作；结果内嵌；做完回地点。
4. **日程页**（NPC 一天在哪）：只写时段与地点，不给任务。

**没有**：任务 Hub、Deep Quest 链、Event Result 页、功能索引 Hub。

### 4.2 事件池写法（照原版）

```twee
<<cleareventpool>>
<<addinlineevent "forest_lost" 3>>
    ...常态事件...
<</addinlineevent>>
<<if Time.season is "winter" and !$daily.forestSnow>>
    <<addinlineevent "forest_snow" 2>>
        ...季节事件...
    <</addinlineevent>>
<</if>>
<<runeventpool>>
```

### 4.3 失败规则

- 普通失败：扣资源/钱/关系，**当天下次同一动作直接给失败提示**（`$daily.failKey`），不锁两天。
- 严重失败：`setback = Time.days + 1`，只锁一天。
- 失败绝不发钱、不发线索。

### 4.4 时间规则

| 动作 | 时间 |
| --- | --- |
| 工作/巡林/守夜一班 | 1:00 |
| 街区移动 | 0:05 |
| 店内短动作 | 0:10–0:20 |
| 吃饭/洗澡 | 0:20–0:30 |

### 4.5 选项文案

- ≤8 字，动作开头（「搬煤」「撬锁」「回去」「跟上去」）。
- 不在标签里写系统名词（进度/阶段/台账/结算）。
- 不写「你可以……」引导句。

- 这批（v50）补的是**门槛与结局**，骨架没动，合并后是「过渡版 dev46」。
- 五人 Hub 新增的深线入口保留（先让人能找到），但下一轮会把 `Deep Quest 1..4C` 拆掉，改成日程 + 场景。
- 下一轮工作包 v51 只做骨架，不再加「任务页」；验收口径改为：地点页 ≤6 动作、无 Result 页、无 Deep Quest 链、班次 1:00。
