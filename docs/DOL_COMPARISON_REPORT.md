# DoL-MP vs 原版 DoL · 全区域结构对照报告

> 对照对象：`dev44` 工作区（3,397 段 / 385 可玩页）vs 原版英文 wiki（693 页）+ 原版 passage 索引（16,087 段）。
> 结论先说：**文笔和氛围有 DoL 味，事件骨架不是 DoL 的骨架。** 六人任务、六地点、四条长线、机制系统，普遍是「一个 Hub 里点几下就完」，缺时间跨度、地点迁移、真实前置、失败后果和不可逆世界状态。

---

## 一、横向结论（所有区域共有的五个病）

### 1. 没有时间/日期门槛
- 六个 NPC 的 Quest 页共 7–9 页/人，**`Time.days` / `Time.hour` 门槛 = 0**，**金钱门槛 = 0**。六条个人线都能在一次访问内从头点到尾。
- 例：阿什 Quest 1–5 约 146 分钟；塞拉父志 10 步约 157 分钟；林恩旧案 9 步约 2:27；莫奈壁画 11 页约 150 分钟；维斯末班夜航 5 章约 2.5 小时；诺艾尔母株 9 节点约 134 分钟。
- 原版：Robin's Quest 明确 "many weeks"；Bailey 租金第 7/14/21/28/35/42/49 天；Temple 守夜仅周日 20:00 连续 9 小时；Farm Assault 第 30 天 + 每 17–24 天；Whitney 街头有 bully timer。

### 2. 失败没有真实后果
- 我们的失败分支几乎只有 `stress / tiredness / pain`，同一分钟可重试；NPC 不会受伤、失踪、创伤，不会失去特质，世界状态不变。
- 原版：欠租每夜被卖；Robin 失踪/创伤/失去 `Robin's Protector`；Docks 战斗失败被鲸吞；Temple 守夜失败本周无阶级；Farm 被烧、Alex 昏迷；Whitney 失败被剥光或永久移除。

### 3. 数值可以刷，门槛形同虚设
- 阿什 `Tier Action` +3/+6 无日锁，约 34 次点击刷满火种；林恩 `Tier Action`/`Note`/`Street 1–3`/`Season` 无日锁，一晚 watch 20→100；塞拉 `Street 1–3`/Daily 杂务无日锁；莫奈 `Tier Action` +6 无日锁；诺艾尔 `Tier Action` +6 无日锁；维斯 `饮热茶` +3 无日锁。
- 名声、安全屋、世界状态也有免费刷压力/物价的入口，无 `$daily`。
- 原版关系值靠每日/每次事件缓慢累积，且常有上限、衰减、负反馈（Rage、Trauma、Dissent）。

### 4. 并行/重复系统，变量串线
- 林恩：`mp-npc-lin` 的 `$mpNpcs.lin.clues/caseStage` 与 `mp-case-board` 的 `$mpCaseBoard.LinColdCase.*` 两套霍克案。
- 诺艾尔：母株线与旧「夜光兰」线共用 `_npc.stage`。
- 塞拉：旧线 `_sera.stage`（0–10）与新线 `_sera.questStage`（0–5）不同步。
- 维斯：旧线 0–10 与新 Deep Quest 1–5 共用 `stage`。
- 莫奈：旧 Quest 0–10 与新 Deep Quest 1–5 共用 `stage`。
- 节日：多处同时存在 `festivalYear` 与 `annualYear` 两套，季节/日期门槛不一致。

### 5. 结局两击直达、可反复改选
- 账本 `Hub → Pay → Ending`、神殿 `Hub → Factions → 结局`、行会 `Bloc Overview → 三宪章`、六地点深层 `Ending A/B`，都不检查前置，写完世界状态还能点另一个改回去。
- 原版用永久状态而非「三选一结局」：桥建成、入教、Robin 失踪、田被烧、Skyscraper 建成/焚毁。

## 五、可以保留、当模板的东西

1. **雾潮水尺**：6 天涨一格 + 物价联动，是原版「租金/袭击计时器」精神。
2. **行会 `wageMod`**：真的进了 `mp-livelihoods` 的打工结算，是全 mod 最实的跨系统咬合。
3. **案件板 3 案 ×6 证据 ×2 假说 + 指认/公开/封存**：最接近原版可重复调查。
4. **账本四档连坐问责**：Overdue/Seize/Transfer/Liquidate 结构像 Bailey 惩罚阶梯。
5. **微节庆日历窗**：3/14–24、6/20–30、12–2 月，是全 mod 唯一有真实日期门槛的系统。
6. **区域池 Chain/Search/Rest + 火把/水位/警戒/线索**：比六地点更像可玩层，可反哺地点重做。

## 六、重做顺序（建议）

### Phase 0：冻结加量
- V49 工作包**暂停发送**。当前任务是「每人 +20 页」，会继续放大错误骨架。
- 先写一份《事件结构标准》：每个事件链必须有解锁前置、每日一步、地点/时段、资源/其他系统、失败后果、一次性结局。

### Phase 1：P0 结构（先做，做完再谈页数）
1. **六人个人线**：拆 `deepStage`；每步 `Time.days` + 地点/时段 + 资源；失败锁 1–3 天并扣信任/资源；结局一次性 + 世界标志被 ≥2 页读取。
2. **数值去刷**：Tier Action / Street / Season / RelDay / Daily 全部加 `$daily` 或每日上限；RelDay 每天 1 幕。
3. **清理并行系统**：林恩两套旧案合一；诺艾尔/塞拉/维斯/莫奈新旧 `stage` 分开或合并；节日两套年份合一。
4. **四条长线**：雾潮补 Stage 3 入链 + Stage 8–10 跨天；账本按天推进 week/逾期；神殿接守夜/告解；行会宪章互斥。
5. **六地点**：入口接回原生地点；每个地点先定一个核心循环（码头整班、学园课表、神殿祈祷/守夜、孤儿院每日事件、森林随机遭遇、高街购物枢纽）；结局一次性。
6. **机制外溢**：安全屋扣维护费/风险进事件；名声进商店/NPC 态度；物价接商店或改成账面折算；世界状态加每日锁。

### Phase 2：P1 深度
- 接原版状态：School→status/delinquency；Temple→purity/grace；Orphanage→hope/rebelliousness；Forest→deviancy/wolf trust；Docks→status/crime。
- 每个地点建加权事件池 + 随机后果；失败后果表（钱/物/伤/名声/犯罪），不只 stress。
- 经济闭环：跑船/打工/约会发工资，接 Bailey 房租。

### Phase 3：P2 体量
- 结构对了再加页数；届时重写 V49，按「每人 +20 页」但每页都必须带门槛/后果。

## 七、建议的试点

先做三个试点，证明「DoL 结构」能落地，再铺开：
1. **塞拉个人线**：旧线 0–10 每天一段 + 父志 6 页靠周锁修表集齐 + 2B/3B/4B 跨天 + 失败留 trauma/rep。
2. **学园地点**：课表 7–17、成绩/违规、留堂；现有杂务挂到具体时段；入口接 Oxford Street 校门。
3. **账本长线**：按天推进 week/逾期；逾期夜触发孤儿院惩罚事件；结局一次性。

试点通过后再决定：六人/六地点/四长线是本地继续做，还是拆成新的 Argon 工作包（结构任务 + 复核）。
