一、包内内容
  game\    游戏本体（Degrees of Lewdity.html，ModLoader 版）
  mods\    三个模组：汉化包、官方图片包、DoL-MP v1.2.0-dev29
  mod-src\ DoL-MP 完整源码
  server\  联机服务器（Node.js，ws 依赖已内置）
  说明书.md  完整中文说明书（推荐先看这个）

二、第一次使用 / 从旧版升级
  1. 双击 start-game.bat 打开游戏（主机可直接双击 start-host.bat）
  2. 按 Alt+M 打开 Mod 管理器（手机点左下角按钮）
  3. 关闭「安全模式」
  4. 如果之前装过旧版 DoL-MP，先点「移除」旧的 DoL-MP
  5. 点「添加模组」，进入 mods 文件夹，全选三个 zip，确定
  6. 点「重新载入」，等待加载完成即可读档或开新档

  升级前建议先导出存档备份。存档在浏览器 IndexedDB（file:// 源），换目录一般不会丢。

三、联机
  1. 房主双击 start-host.bat（需要 Node.js 18+），脚本会显示本机 IPv4 并启动端口 8787
  2. 游戏右下角「联机」填昵称与服务器地址：
     同机双开  ws://127.0.0.1:8787
     局域网    ws://主机IP:8787
     Radmin / ZeroTier / Tailscale 等虚拟局域网填虚拟网卡 IP
  3. 房主「创建房间」，把 4 位房间码发给朋友；朋友输入房间码「加入」

四、手动启动服务器
  cd server
  node server.js

  依赖缺失时执行 npm install。

五、常见问题
  Q: Mod 管理器看不到 DoL-MP？
  A: 确认三个 zip 都在 mods 里、添加时全选，然后点「重新载入」。
     装过旧版的，先移除旧 DoL-MP。

  Q: 打开是英文？
  A: 汉化包 ModI18N 需要一起添加并重新载入。

  Q: 联机连不上？
  A: 先看服务器窗口有没有报错；同机用 127.0.0.1，局域网用主机 IPv4，
     虚拟局域网用虚拟网卡 IP；防火墙放行 Node.js 和 8787 端口。

  Q: 提示 Node.js not found？
  A: 安装 Node.js 18+ 后重新运行 start-host.bat。
